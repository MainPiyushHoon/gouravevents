# Gourav Events — Luxury Wedding Studio

> Extraordinary destination weddings where royal heritage meets deep emotion across Jaipur, Udaipur, Jim Corbett, and Rishikesh.

A modern, high-performance web experience crafted with Next.js 16 (Turbopack), React 19, Tailwind CSS, Lenis smooth scrolling, and Swup.js component transitions.

---

## ✦ Core Features

- **Light Luxury Palette**: Curated Warm Alabaster (`#FAF8F5`), Deep Burgundy (`#3E1522`), and Champagne Bronze (`#8C6843`).
- **Buttery Inertia Scrolling**: Lenis smooth scroll layer configured with natural momentum decay and native mobile touch preservation.
- **Dynamic Destination Showcases**: Swup.js transitions across curated destination portfolios (Jaipur, Udaipur, Jim Corbett, Rishikesh).
- **Direct Founder-Led Conversion**: Integrated booking validation generating custom WhatsApp inquiries directly to the founder.
- **Standalone Multi-Page Routing**: Complete dedicated routes for `/weddings`, `/destinations`, `/services`, `/about`, and `/enquire`.

---

## ✦ Getting Started

### Prerequisites

- Node.js 20+
- pnpm 9+

### Installation

```bash
# Install dependencies
pnpm install

# Start local development server
pnpm dev

# Type check
pnpm run check

# Build production bundle
pnpm build
```

Open [http://localhost:3000](http://localhost:3000) to view the application in the browser.

---

## ✦ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI Library**: React 19
- **Styling**: Tailwind CSS, Vanilla CSS Design Tokens
- **Smooth Scroll**: Lenis (`lenis/react`)
- **Transitions**: Swup.js (`swup`)
- **Form Validation**: Zod & React Hook Form
- **Icons**: Lucide React
